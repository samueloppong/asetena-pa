# Agent Directives: Ghana Card NFC Verification Architecture

2. Pipeline Sequence:
   - Step 1: Camera OCR reads MRZ string (Doc Num, DOB, Expiry).
   - Step 2: Pass MRZ keys to NFC engine to compute BAC/PACE session keys.

   - Step 4: Run Passive Authentication against Ghana CSCA certs.
   - Step 5: Capture live selfie with 3D liveness detection.
   - Step 6: Compare live selfie vector against DG2 image vector.
   - Step 7: Construct final JSON matching `verification-payload.schema.json` and post to verification endpoint.
